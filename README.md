> 📌 **Catatan Instalasi:**
> 1. Unduh file APK di atas ke smartphone Android Anda.
> 2. Buka file yang diunduh dan pilih **Install / Pasang**.
> 3. Jika muncul konfirmasi keamanan *Aplikasi dari sumber tidak dikenal*, pilih **Izinkan / Tetap Pasang (Install Anyway)**.
> 4. Buka aplikasi dan masukkan lisensi aktivasi Anda untuk mulai menggunakan bot.
